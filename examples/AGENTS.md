# Project Agent Instructions

Use these instructions for this repo only.

## Scope

- Stay inside this repository unless the user explicitly asks otherwise.
- Do not edit secrets, auth files, runtime state, generated logs, local databases, or personal memory exports.
- If the user names exact files, edit only those files.

## Working Style

- Inspect before editing.
- Prefer small, reviewable changes.
- Use existing project patterns before adding new ones.
- Do not add hooks, installers, MCP configs, or automation unless explicitly requested.

## Verification

Before claiming completion, provide fresh evidence:

- tests/build/lint when code changed
- rendered or manual review when docs changed
- file tree and checklist when packaging a repo

If verification cannot be run, say so and explain the remaining risk.

## Handoff

End substantial work with:

- changed files
- verification evidence
- open items
- next action
- anything intentionally left untouched
